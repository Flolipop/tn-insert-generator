# Traveler's Notebook Insert Generator

Browser-based tools for generating printable Traveler's Notebook inserts. Design, customize, and print your own TN refills at home — no apps or subscriptions needed.

## Tools

### Weekly Planner (`weekly.html`)
Full-featured weekly planner insert with:
- Daily pages with mood tracker, habit checkboxes, and custom fields
- Weekly habit tracker grid
- Monthly calendar, goals page, mood calendar, expense tracker
- Customizable covers (multiple designs, accent colors, custom images)
- Configurable graph/metrics pages
- Theme presets and full color customization

### Gym Log (`gym.html`)
Training log insert with:
- Workout split templates (PPL, Upper/Lower, Full Body, Bro Split, custom)
- Exercise log pages with sets/reps/weight tracking
- Monthly progress and body measurement pages
- Program import from Excel/CSV files
- Monthly calendar and summary pages

## Features

Both generators share:
- **Multiple paper sizes** — A4, US Letter, US Legal, A3
- **5 notebook sizes** — Passport, B6 Slim, Personal, A5 Slim, Regular, plus custom dimensions
- **Print-ready output** — Crop marks, fold lines, duplex flip options
- **Assembly guide** — Optional printed instructions for folding and binding
- **Live preview** — Page view, book spread view, and print layout
- **Themes** — Built-in color presets or fully custom palette
- **Font selection** — Multiple built-in fonts plus custom font support
- **Settings import/export** — Save and share your configurations as JSON
- **Mobile-friendly** — Responsive sidebar UI

## Usage

1. Open `weekly.html` or `gym.html` in any modern browser
2. Configure your insert using the sidebar controls
3. Click **Generate** to build the pages
4. Use **Print / PDF** to print directly or save as PDF
5. Cut along crop marks, fold at the center line, and staple the spine

## Printing Tips

- Print at **100% scale** (no fit-to-page)
- Use **landscape** orientation
- Enable **duplex** (two-sided) printing
- Choose the correct **flip edge** (long or short) to match your printer's duplex mode
- Use a paper trimmer for clean cuts along crop marks
